# Liquid Glass

Current scope: [Issue #5](https://github.com/librecosta/liquid-glass/issues/5), LG-C3, on `dev`.

- `src/core/`: the only rendering engine. Core DEFAULTS are Balanced: dispersion=0.8, sat=1, edge=0, rim=0.80; other defaults and math/maps/encoding/cache/resize mechanisms are unchanged. Legacy facade stays internal.
- `src/index.ts`: public `createLiquidGlass`, `DEFAULTS`, `QUALITY_PRESETS`, `supported`, `LiquidGlass*` types. `src/react/`: only `useLiquidGlass` and types. No public prefab components, global management or default facade export. One package, two JS entries and optional CSS.
- `src/styles.css`: minimal low-specificity effect rules only; native DOM/layout/styles belong to applications. `src/components-demo.tsx` is a Hook DIY example, not a component library. Inputs use a separate decorative glass layer beneath a transparent native input.
- `src/main.tsx`, `src/scene-view.tsx`, `src/drag.ts`: single-engine Playground. First paint/Reset and Hook DIY use actual Balanced defaults, no hidden overrides. Position writes coalesce per rAF; final React state on release/cancel. Quality switching must retain DOM/instance ownership and show effective parameter values.
- `src/quality.ts`: Balanced/Fast explicitly specify all four quality parameters; Fast uses dispersion=0. Reference pins the complete original b257c17 defaults as an independent named object, solely for historical regression. Optical Balanced is only a historical experiment. No further tuning beyond the approved C3 values.
- `tests/golden/math.json`, `reference.json`, `reference/`: frozen original math/map/SVG/Chrome pixels; tests must explicitly select Reference, never regenerate to hide regressions. `tests/golden/c3/`: separate Balanced/Fast fixtures. `tests/consumer/` and `scripts/verify-consumer.mjs`: real external tarball, strict types/export contracts/SSR/StrictMode/native forms/lifecycle/cache/fallback, unconfigured core/Hook and repeated quality switching. The old component declarations must stay absent from public exports.
- `src/assets/forest.jpg`: local demo-only photo, never a library dependency. Provenance/permission in JSON and THIRD_PARTY_NOTICES; full adapted MIT in `licenses/Hyalite-MIT.txt`, included in tarballs.
- `docs/lg-c3-defaults.md`: current review guide/results. `scripts/measure-switching.mjs`: warm switching then five-card drag samples at DPR1/2. LG-A/B/C/C2 reports, captures and measurement scripts refer to their recorded commits/configurations; do not overwrite them with current default measurements.

Node 24+, `npm ci`, `npm run check` (Chrome; `LG_CHROME` override). `dist/` is the library, `dist-playground/` the demo. No main merge, npm publication, Release, UI framework, new renderer/Worker or unauthorized algorithm rewrite. Keep Reference and third-party license notices intact.
