# Liquid Glass

Current scope: first public v0.1.0 release following Issue #6 and the owner's explicit authorization. Preserve the owner's removal of `private`; normal dev→main PR merge, public npm publication, annotated v0.1.0 tag and GitHub Release are authorized in that order, after validation. No force push.

- `src/core/`: the only rendering engine. Core DEFAULTS are Balanced: dispersion=0.8, sat=1, edge=0, rim=0.80; other defaults and math/maps/encoding/cache/resize mechanisms are unchanged. Legacy facade stays internal.
- `src/index.ts`: public `createLiquidGlass`, `DEFAULTS`, `QUALITY_PRESETS`, `supported`, `LiquidGlass*` types. `src/react/`: only `useLiquidGlass` and types. No public prefab components, global management or default facade export. One package, two JS entries and optional CSS.
- `src/styles.css`: minimal low-specificity effect rules only; native DOM/layout/styles belong to applications. `src/components-demo.tsx` is a Hook DIY example, not a component library. Inputs use a separate decorative glass layer beneath a transparent native input.
- `src/main.tsx`, `src/scene-view.tsx`, `src/drag.ts`: single-engine Playground. Public canvas responds to its stage; `?fixture=1` preserves the original 500×480 scene, DOM, copy and geometry independently of language/responsive CSS. First paint/Reset and Hook DIY use actual Balanced optical defaults, no hidden overrides. Position writes coalesce per rAF; final React state on release/cancel. Quality switching must retain DOM/instance ownership and show effective parameter values.
- `src/i18n.ts`, `src/site-ui.tsx`, `src/style.css`: shared English/Simplified Chinese dictionary, native controls and public website styling. English by default; valid `lang=en|zh-CN` URL overrides persisted language. Use Vite's `BASE_URL` for internal navigation so `/liquid-glass/` production builds remain inside the project. Keep translated titles, feedback and accessible labels complete. Public styles belong under `.site`/`.public-scene`; never restyle the fixed fixture. Inspector uses page scrolling and native details; no UI framework or continuous decorative animation.
- `src/quality.ts`: Balanced/Fast explicitly specify all four quality parameters; Fast uses dispersion=0. Reference pins the complete original b257c17 defaults as an independent named object, solely for historical regression. Optical Balanced is only a historical experiment. No further tuning beyond the approved C3 values.
