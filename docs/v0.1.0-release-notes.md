LibreCosta Liquid Glass adds SVG refraction to your own HTML, with a native TypeScript ESM core and a single React 19 Hook.

- Bind `createLiquidGlass` or `useLiquidGlass` to elements you design. Layout, styles and native interactions stay under your control.
- Start with Balanced defaults; switch an existing instance to Fast when performance matters.
- Configure instances independently, update options live, react to resizing and clean up explicitly.
- Use SSR-safe imports and CSS blur fallback where SVG backdrop refraction is unavailable.

The core installs without React. The React entry requires React 19; effect CSS is optional. Historical Reference remains available for comparisons. Real Safari/Firefox and physical-device coverage remain limited; see Browser Support in the README.

During RC review, install the locally built `librecosta-liquid-glass-0.1.0.tgz` as described in the [README](../README.md). Replace this RC installation sentence with the verified registry installation command only after a successful public npm publication.
