# v0.1.1

Optional material CSS for the existing headless TypeScript core and React Hook. Import `@librecosta/liquid-glass/materials.css` alongside the base `styles.css` to use Clear, Soft or Prismatic on your own HTML.

- Clear keeps the original Playground tint. Soft uses 7% tint, or 6% with an explicit light theme. Prismatic adds neutral gradients and gloss.
- Select material and theme with `data-lg-material` / `data-lg-theme`. Opt into decoration with `data-lg-decorate` only when the host's `::after` is free. Native inputs keep an independent decorative background layer.
- Layout, positioning, radius, typography, text contrast, focus and native interaction remain under application control. Material and optical Quality are independent; no material JS API or components are added.
- Windows development checkouts can use `npm run dev:stop [-- --port 5174]` to stop verified Vite dev/preview services safely.

Core and React Hook APIs, the base stylesheet, Balanced/Fast/Reference, optical defaults, caches and rendering algorithms are unchanged. The core still installs without React; the Hook requires React 19.

Registry installation, once this version is available:

```sh
npm install @librecosta/liquid-glass@0.1.1
```
